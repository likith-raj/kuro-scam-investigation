?? PROJECT OVERVIEW

On July 29, 2026, a suspicious scam application named "Kuro" was installed on a Windows 11 system. The app appeared legitimate but was designed to steal banking credentials and personal data. Static and dynamic analysis were performed using VirusTotal, Process Explorer, Registry Analysis, and Network Monitoring.

The application was identified as an Electron-based credential stealer. It uses registry persistence, process masquerading, and screen capture to steal sensitive information. 1 malicious detection was confirmed on VirusTotal.

?? REMEDIATION ACTIONS

?? IMMEDIATE ACTIONS TAKEN

  • Network isolated immediately
  • splunkd.exe and python.exe terminated
  • Registry persistence entries deleted
  • Malware folder removed from AppData
  • System rebooted to clear socket buffers

?? POST-INCIDENT SECURITY

  • All passwords changed immediately
  • 2FA enabled on all accounts
  • Bank accounts monitored for suspicious activity

?? LESSONS LEARNED

  • If it sounds too good to be true, it probably is - Money for screen sharing is a red flag
  • Always check running processes - splunkd.exe was the giveaway
  • Real money can be used as bait - ?301 was to gain trust before the big steal
  • Verify before installing - Always check app reviews and reputation
  • Report suspicious activity - Helps others avoid the same trap
