THE HONEY TRAP WHAT HAPPENED

I discovered a mobile and web application called "Kuro" that promised to give real money for sharing screen timeRs 301 as an Amazon voucher to build trust. However, I noticed something suspicious a process named splunkd.exe was running in the background without my knowledge.

This was a honey trap the attacker uses small payments to gain your trust, while the app secretly captures your screen activity, keystrokes, and browser sessions

WHAT IS BAIT IN CYBERSECURITY

Bait means something attractive used to trap someone. In cybersecurity, attackers use bait to trick victims into doing something dangerous. Like how you put cheese in a mouse trap.

BAIT ELEMENTS IN KURO SCAM

  • Money: Rs 301 Amazon voucher real money equals Trust
  • Easy Work: Just share your screen looks simple
  • Legitimate App: Professional looking app looks real
  • Urgency: Earn now makes you act fast

HOW THE BAIT WORKED

  • You see Earn Rs 301 by sharing screen
  • You think Easy money why not
  • You install the app
  • You get Rs 301 voucher real money
  • Trust is built
  • Malware steals everything in background

WHAT IS SPLUNKD EXE AND HOW ATTACKERS HIDE

splunkd.exe is a real program from Splunk a legitimate company. But in Kuro Scam, attackers use the SAME NAME to hide their malware.

REAL SPLUNKD EXE

  • Purpose: Log monitoring and analysis
  • Location: C Program Files Splunk bin splunkd.exe
  • Signature: Digitally signed by Splunk Inc
  • Service: Splunkd Windows Service
  • Behavior: Collects logs
  • Network: Sends logs to Splunk server
  • File Size: 50 to 100 MB

FAKE KURO SPLUNKD EXE

  • Purpose: Screen capture and stealing
  • Location: C Users hp AppData Local KuroWindows current splunkd.exe
  • Signature: No valid signature
  • Service: No service runs as app
  • Behavior: Captures screen and keystrokes
  • Network: Sends to C2 server trykuro.app
  • File Size: Only 176 KB suspicious

THE MASQUERADING TECHNIQUE

  • Step 1: Attacker creates malware
  • Step 2: Names it splunkd.exe
  • Step 3: Puts it in AppData Local KuroWindows
  • Step 4: Adds to Registry HKCU Run KuroWindows
  • Step 5: Starts automatically with Windows
  • Step 6: You see splunkd.exe in Task Manager
  • Step 7: You think Oh Splunk is running
  • Step 8: Malware runs secretly forever

THE SCAM MECHANISM

HOW THE HONEY TRAP WORKS
