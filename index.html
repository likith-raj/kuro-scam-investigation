?? INCIDENT OVERVIEW - WHAT HAPPENED

I discovered an app called "Kuro" that promised to give money for sharing screen time. I installed it, shared my screen, and actually received an Amazon voucher worth ?3,350splunkd.exe was running in the background, which I never installed.

This was a honey trap - the app gives you small money to build trust, but in the background, it steals your screen activity, keystrokes, and browser sessions

?? HOW THE SCAM WORKS

THE HONEY TRAP TECHNIQUE

  • Bait: "Earn money by sharing screen" - looks legit
  • Reward: ?3,350 Amazon voucher (real money to build trust)
  • Hidden: splunkd.exe runs in background (masquerading)
  • Stealing: Screen captures + keystroke logging
  • Exfiltration: Data sent to C2 server in real-time

?? LESSONS LEARNED

  • If it sounds too good to be true, it probably is - Money for screen sharing is a red flag
  • Always check running processes - splunkd.exe was the giveaway
  • Real money can be used as bait - ?3,350 was to build trust
  • Verify before installing - Always check app reviews and reputation
  • Report suspicious activity - Helps others avoid the same trap
