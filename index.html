?? PROJECT OVERVIEW

On July 29, 2026, a suspicious scam application named "Kuro" was installed on a Windows 11 system. The app appeared legitimate but was designed to steal banking credentials and personal data. Static and dynamic analysis were performed using VirusTotal, Process Explorer, Registry Analysis, and Network Monitoring.

The application was identified as an Electron-based credential stealer. It uses registry persistence, process masquerading, and screen capture to steal sensitive information. 1 malicious detection was confirmed on VirusTotal.

  • Monitor processes for masquerading (splunkd.exe was suspicious)
  • Regular registry checks for persistence entries
  • Use multiple antivirus engines (VirusTotal confirmed malicious)
  • Report suspicious domains to threat intelligence platforms
