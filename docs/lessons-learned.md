# Lessons Learned from Kuro Scam Incident 
 
## ?? Security Lessons 
 
1. **Verify Applications** 
   - Always check app reviews and ratings 
   - Download only from official sources 
   - Verify digital signatures 
 
2. **Monitor System Activity** 
   - Use Process Explorer for suspicious processes 
   - Check Registry for persistence 
   - Monitor network connections 
 
3. **Response Preparedness** 
   - Have incident response plan ready 
   - Know kill commands 
   - Keep threat intel tools ready 
 
## ?? Technical Takeaways 
 
- Electron apps can be malicious 
- Process masquerading is common 
- Registry persistence is effective 
- Multiple AV engines needed 
- Report IOCs to threat platforms
