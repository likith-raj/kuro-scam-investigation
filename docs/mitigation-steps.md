# Mitigation Steps for Kuro Scam 
 
## ?? Immediate Actions 
 
1. Disconnect network 
2. Open Admin Command Prompt 
3. Kill malicious processes 
4. Delete registry entries 
5. Remove malware folders 
6. Run AV scan 
7. Reboot system 
 
## ?? Password Changes 
 
- Email passwords 
- Bank account passwords 
- Social media passwords 
- UPI/Banking PIN 
 
## ?? Monitoring 
 
- Monitor bank statements 
- Check transaction history 
- Watch for suspicious logins 
- Review credit reports 
 
## ?? Emergency Contacts 
 
- Cyber Crime Helpline: 1930 
- Cyber Crime Portal: cybercrime.gov.in 
- Bank Fraud Department: Check card back
